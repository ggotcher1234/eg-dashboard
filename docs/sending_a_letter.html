Sending a letter from the dashboard

Welcome letters, scheduling letters, research emails, invoices — they all work the same way.

  1. Click Open draft & copy letter. Your own email program opens a new message with the To, Cc and Subject already filled in. The message itself is empty on purpose.
  2. The letter is on your clipboard. Right-click inside the empty message and choose Paste. The whole letter drops in.
  3. Read it over, make any edits you want, and send.
Why the draft opens empty Your signature is already sitting in that blank message, with the cursor above it. Pasting puts the letter where it belongs — in front of your signature, not behind it. If we filled the message in for you, Outlook would treat the letter as quoted text and park your signature on top of it.

If the wrong program opens

Some browsers send these drafts to webmail instead of the mail app you actually use. Set it once and it stays set.

Windows Start → Settings → Apps → Default apps. Search for your mail program, open it, and set it as the default for MAILTO.
Mac Open the Mail app → Settings → General → Default email reader, and choose Outlook (or whichever app you use). If Chrome keeps opening Outlook on the web, go to Chrome Settings → Privacy and security → Site settings → Additional permissions → Protocol handlers and remove outlook.office.com.

Questions that come up

Nothing pasted — the message is still blank.

The copy didn't take. Go back to the dashboard and use the Copy letter button next to it, then right-click and Paste again.

Do I have to use the draft it opens?

No. Copy letter puts the text on your clipboard without opening anything, and the addresses are on screen for you to copy too. Start the message however you normally would.

Can I change the letter?

Yes — once it's pasted into your message it's yours. Edit it like any other email before you send.

One thing to remember The draft opens empty and the letter is on your clipboard. Right-click, Paste, send.
